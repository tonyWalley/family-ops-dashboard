Bank CSV → JSON Intake

Standardized collection: select USAA, Chase, or PayPal and import the bank export. The app converts each row into a common transaction schema inside the private JSON. Imported rows are marked needs_review and do not change the Cash Plan, budgets, or forecasts until they are reviewed.

The standardized record preserves the source, dates, description, amount, source type/category, transaction IDs when available, and the original non-empty CSV fields. Exact re-imports are deduplicated. Financial categorization remains a ChatGPT review step.

Shared Workflow

Bank-review workflow: Bank CSV → import here → Share as text or Share JSON file → ask ChatGPT to inspect the current JSON. ChatGPT can review every needs_review bank transaction, reconcile transfers/PayPal funding duplicates, categorize the rows, and return updated JSON for re-import.

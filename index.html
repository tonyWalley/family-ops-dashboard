Best Low-Effort Shared Workflow

This version is designed for a future direct Dropbox connector. For now it saves instantly on each device and exchanges one structured JSON file. All calculations, tasks, notes, and statuses are stored in that file.
Before editing: import the newest WFOS_CURRENT_STATE.json from the shared Dropbox folder.
Edit normally: changes autosave locally on the current phone.
After editing: tap Share current JSON and save or replace WFOS_CURRENT_STATE.json in Dropbox.
Tell the other person: “I updated the dashboard” so they import before making their next changes.

Conflict Protection

The JSON includes a revision number, last-updated time, and updater name. Import warns when the incoming file is older than the state on the device. This does not create true simultaneous editing, but it sharply reduces accidental overwrites.

One-file discipline: keep the shared filename exactly WFOS_CURRENT_STATE.json. Timestamped update files can be kept as backups, but the fixed filename is the current shared state.

Future Optional Upgrade

A direct Dropbox OAuth/PKCE sync adapter can be added later without rebuilding the dashboard. That would let both phones read and write the same JSON file directly. It should be added only after this local/import-export version proves useful.
